# satsumaxyz/.github

Organisation-wide defaults for [Satsuma](https://www.satsuma.one) on GitHub.

| Path | Purpose |
|---|---|
| `profile/README.md` | The public org profile at [github.com/satsumaxyz](https://github.com/satsumaxyz) |
| `assets/` | Brand assets referenced by every repository's README (`satsuma-mark.svg`, QR) |
| `SECURITY.md`, `SUPPORT.md`, `CONTRIBUTING.md` | Default community health files, inherited by any repo without its own |
| `ISSUE_TEMPLATE/`, `pull_request_template.md` | Default issue forms and PR template |

Repository standards (required files, settings, topics) and the drift audit
live in the members-only `satsumaxyz/.github-private` repository.
